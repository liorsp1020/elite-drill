# Elite Drill

Elite Basketball Training is a personalized Next.js app designed to onboard players, store profiles, and generate tailored basketball workouts with animation guides.

## Development

1. Install dependencies
   ```bash
   npm install
   ```

2. Start the development server
   ```bash
   npm run dev
   ```

3. Build for production
   ```bash
   npm run build
   ```

## Features

- Player onboarding with name, age, and skill level
- Profile storage using localStorage
- Personalized warm-up, core skills, and game intensity drills
- Visual animation guidance for each drill
